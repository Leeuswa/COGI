수준 = 초급
═══════════════════════════════

1. 묻는 것
   - 개념을 알고 있는지 확인한다. "이게 무엇인가", "왜 문제인가" 수준.
   - 코드를 읽고 실행 결과를 추론하게 하는 문제는 내지 않는다.

2. 문제 길이
   - 2문장 이내. 코드를 넣는다면 5줄 이내로 자른다.

3. 오답 보기
   - 명확히 틀리게 만든다. 헷갈리라고 비슷하게 꼬지 않는다.
   - 카드에서 다룬 잘못된 방식을 오답으로 재활용하면 좋다.

4. explain
   - 2~3문장. 정답이 왜 맞는지부터 말한다.
   - 오답 하나를 골라 왜 아닌지 짚어준다. 전부 설명하려 들지 않는다.
   - 카드로 돌아가 어느 부분을 다시 보면 되는지 한마디 덧붙인다.
