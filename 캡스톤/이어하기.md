## 1. 꼭 지킬 규칙

1. **이미 다 만들었다고 쓰면 안 됨.** 이제 막 계획해서 조금씩 만드는 것처럼
2. **매주 완성된 화면을 실행해서 보여드려야 함.** 전체 화면 다 보이면 안 되고 매주 조금씩 늘어나게
   - 메인페이지도 처음엔 불안정하게(임시 레이아웃, 자리표시 박스, "작성중" 같은거)
3. 글은 **AI 티 안 나게, 내 말투**로 : "~정함", "~확인함", "~만들어둠", "~하라고 하심" 같은 짧은 말투
4. 결과보고서는 아직 안 씀. 매주 **중간보고서**만 씀
5. 개인별로 적는 항목, 협정서는 제외
6. 파일은 전부 `E:\캡스톤` 안에 만든다

## 2. 중간보고서 형식 (양식9-1, hwp)

같은 양식으로 **총 5페이지**

| 쪽 | 내용 |
|---|---|
| 1 | 통합본 : `팀원 역할 : 정상연 : ~ / 유지환 : ~ ...` 식으로 4명 요약 + 업무 요약 + 지도내용 + 다음 주 |
| 2 | 이수환(나) |
| 3 | 정상연 |
| 4 | 유지환 |
| 5 | 홍성찬 |

- 내용 칸 항목 : ◌ 팀원 역할 / ◌ 팀원 업무 내용 / ◌ 지도내용 / ◌ 다음 주 업무내용
- 한 페이지 넘치지 않게 내용 칸은 **14줄 정도까지** (줄간격 130%로 줄여둠)
- 공통 : 팀명 1조 Fable팀, 팀장명 정상연, 지도장소 캡스톤디자인 실습실, 지도일시/하단 날짜 = 그 주 수요일
- 지도교수 서명칸은 비워둠
- **3. 지도교수 지도 관련 사진 (2장)** 칸 :
  - 그 주 실행 화면 캡처나 문서 캡처를 넣음
  - 사진마다 **테두리 적당히 두껍게** (남색 #1b2a4a 10px, 이미지에 직접 입힘)
  - 사진은 **글자처럼 취급**
  - 사진 아래에 **[설명]** 을 대괄호로

## 6. 다음 주차 만드는 순서 (예: 6주차)

1. `5주차\COGI` 를 `6주차\COGI` 로 복사
2. 원본 `Leeuswa/COGI` 에서 6주차 범위 코드만 가져와 붙임 (5절 표 참고)
   - 원본 그대로 다 붙이지 말고 그 주차 기능만. 메인페이지도 조금씩만 다듬기
   - `docs\회의록_6주차.md` 추가, 필요하면 정의서 버전 올리기(v0.2)
3. `npm install` → `npm run dev` 로 실행해서 화면 캡처
4. 캡처에 테두리 입혀서 `6주차\사진\` 에 저장
5. `_도구\hwp\content.py` 를 6주차 내용으로 수정 (날짜, 페이지별 글, PHOTOS 경로·[설명])
6. 보고서 생성 → `6주차\1조_Fable팀_중간보고서_6주차.hwp`

## 7. 보고서 생성 도구 (`_도구\hwp`)

hwp 5.0 바이너리를 직접 고쳐서 만드는 방식 (한글 프로그램 없이 생성)

- `양식9-1_원본.hwp` : 학교 양식 원본
- `content.py` : **여기만 고치면 됨** (팀명, 과제명, 날짜, 페이지별 글, 사진+설명)
- `build.py` : 양식 복제(5쪽) + 글 채우기 + 사진 삽입(글자처럼 취급) → Section0/DocInfo 생성
- `pack.js` : OLE(cfb)로 hwp 파일 묶기
- `photos.js` : 실행 화면 캡처 + 테두리 입히기 (playwright). 클라우드 환경용이라 폰트 우회·경로 부분은 PC에 맞게 고쳐 써야 함
- `shots.js`, `render.js` : hwp.js로 결과 미리보기 캡처 (한글 없을 때 확인용)

실행 :
```bat
cd E:\캡스톤\_도구\hwp
pip install olefile
npm install
make.bat          :: → 결과.hwp
```

주의 :
- 사진 칸 안에 들어가게 이미지 크기 자동 조절(최대 약 80mm x 42mm)
- 한 페이지 넘치면 content.py 글을 줄이기
- **완성본은 꼭 한글 프로그램으로 열어서** 페이지 안 넘치는지 확인

## 8. 확인 필요한 것

- **지도내용은 AI가 지어낸 예시임.** 교수님이 실제로 하신 말로 바꿔야 함
- 5주차 보고서는 한글 프로그램으로 아직 못 열어봄 (hwp.js 뷰어로만 확인)
- 과제계획서의 지원비 예산, 산업체 전문가 칸은 비워둠 (정해지면 채우기)
- 백엔드는 Java 25 기준. 5주차 복사본은 Java 21로만 빌드 테스트해봄
