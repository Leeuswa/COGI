# 자료 / 레퍼런스 수집

5주차에 팀원들이 각자 찾아온 거 모아둔 문서. 계속 추가함

## 1. 비슷한 서비스

| 서비스 | 뭐 하는 건지 | 참고할 점 | 아쉬운 점 (우리가 다르게 할 부분) | 조사 |
|---|---|---|---|---|
| CodeRabbit (coderabbit.ai) | PR에 AI 리뷰 코멘트 달아줌 | PR 요약, 라인별 코멘트 | 리뷰로 끝남. 내가 뭘 자주 틀리는지는 안 알려줌 | 홍성찬 |
| GitHub Copilot 코드 리뷰 | GitHub 안에서 AI 리뷰 | GitHub이랑 바로 붙어있음 | 학습 기능 없음, 유료 | 홍성찬 |
| SonarQube / SonarCloud | 정적 분석, 코드 품질 점수 | 이슈 심각도 나누는 방식, 대시보드 | 규칙 기반이라 설명이 딱딱함 | 이수환 |
| DeepSource | 정적 분석 + 자동 수정 | 카테고리 분류(버그, 성능, 보안 등) | 초보자가 보기엔 어려움 | 홍성찬 |
| 프로그래머스, 백준 | 코딩 문제 풀이 | 문제 풀고 기록 쌓이는 구조 | 내 코드 약점 기반이 아님 | 정상연 |
| 인프런 | 개발 강의 | 강의 추천 | 내 약점이랑 연결 안 됨 | 유지환 |
| 듀오링고 | 언어 학습 앱 | 연속 학습(streak), 캐릭터로 계속하게 만듦 | - | 정상연 |
| 다마고치 | 캐릭터 키우기 | 안 돌보면 캐릭터 상태 나빠지는 구조 → 코기 키우기 아이디어 | - | 정상연 |

정리 : 리뷰 해주는 서비스랑 공부 시켜주는 서비스는 많은데, 리뷰 결과로 공부까지 이어주는건 못 찾음 → 이걸 우리 차별점으로
