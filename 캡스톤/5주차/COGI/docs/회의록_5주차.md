# 5주차 회의록

- 일시 : 2026.09.30
- 장소 : 캡스톤디자인 실습실
- 참석 : 정상연(팀장), 유지환, 홍성찬, 이수환

## 1. 주제 확정

- 후보 : 스터디 매칭 앱 / 코드 리뷰 도구 / 개발자 학습 플랫폼
- 코드 리뷰를 받아도 그때만 고치고 끝나는 문제가 있다는 얘기가 나와서, 리뷰 결과를 공부로 이어주는 쪽으로 정함
- 이름은 Code Guide 줄여서 COGI(코기). 캐릭터도 코기로 가기로 함

## 2. 핵심 흐름

리뷰 → 약점 분석 → 학습카드/퀴즈 → 다시 리뷰

- 같은 지적 3번 쌓이면 약점으로 봄 (숫자는 나중에 조정 가능)
- 공부 계속하게 만드는 장치로 코기 키우기(다마고치) 넣자는 의견 → 우선순위는 뒤로

## 3. 역할 분담

| 이름 | 담당 |
|---|---|
| 정상연(팀장) | 일정 관리, 학습카드·퀴즈·AI 학습계획, 프롬프트 설계, 모바일 화면 |
| 유지환 | 관리자 페이지, 요금제·결제, 약관, 비로그인 체험 리뷰 |
| 홍성찬 | AI 코드 리뷰(PR 리뷰, 이슈 판정·재검증, 웹훅), 리뷰 히스토리 |
| 이수환 | 로그인·회원가입·2단계 인증, 성장추이·주간리포트, 서버 배포 |

## 4. 기술 스택

- 프론트 : React + Vite + TypeScript
- 백엔드 : Spring Boot, JPA, MariaDB, Redis(필요하면)
- AI : Claude, GPT, Gemini, Groq 중에서 비교해보고 여러 개 쓰는 구조로
- 협업 : GitHub (main / develop / feature 브랜치), 디스코드

## 5. 정한 것

- 매주 회의 끝나고 되는 화면 하나씩은 보여줄 수 있게 하기
- 12주차에 배포까지 끝내는게 목표
- PR은 한 명 이상 보고 머지

## 6. 다음 주까지

- 유지환 : 관리자 화면 와이어프레임, 요금제 표 정리
- 홍성찬 : 리뷰 API 설계, LLM 응답 비교 결과 정리
- 이수환 : 회원 테이블 설계, 로그인 API 시작, 이메일 인증 방식 조사
